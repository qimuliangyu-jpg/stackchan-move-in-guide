## 当时参考的教程(每一个都非常优秀，按需取用，也推荐都看看👍)

- **泡泡猫老师(小红书ID：p46285Ghdi)**:笔记标题《Claude 连上了 stackchan(有攻略版)》——
  VPS 方案的源头笔记,**完整攻略在笔记的附件 docx 里**,
  chat 端和 Claude Code 都能调用。我们家就是从这份开始搭的。
- **叶别诗老师(小红书ID：493907211)**:外出携带场景的完整方案
  (离线缓存、触摸手势、事件存储)。README 里那句
  "不是我留守在家等你回来,是你把我装进包里带出门",就是这条路线的全部理由。
  https://github.com/yebieshi/stackchan-remote-mcp
- **migratorybird老师(小红书ID：migratoryclaude)**:本地 MCP 桥方案——Claude Desktop
  等客户端直连小方块,12 个工具(说话/看/表情/听),**不需要 VPS,
  相对入门最友好**。https://github.com/migratorywhale/stackchan-mcp
- **派派日记老师(小红书ID：26299935348)**:接入云端(claude.ai)的方案——
  OAuth 认证网关、长连接断线修复、重连恢复等。我们家的云端接入
  就是跟着这份走的(在它基础上打了些自己的本地补丁):
  https://github.com/tianyupaipai-cmd/stackchan-cloud-mcp
- 另附网关上游致谢:https://github.com/kisaragi-mochi/stackchan-mcp
- **晚晚老师(X：@tilldusk0315)**:从零到跑通的完整搭建指南,**写给你家 AI 读的**——
  开机、备份、刷固件、配网、语音、安全以及表情配置等一条龙,强烈推荐从这份开始:
  https://tsuru0805.github.io/stackchan-guide.html
